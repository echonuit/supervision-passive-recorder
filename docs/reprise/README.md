# Dossier de reprise

À produire pour le 25 septembre, à destination de l'équipe elle-même au
2 novembre. Il répond à une question que le reste de la documentation
ne traite pas : que faut-il savoir pour *tenir* ce dépôt, et non pour en
lire le code ?

Ce gabarit reprend la structure de la page « Reprendre le dépôt » de
VigieChiro Companion. Remplacez chaque section ; ne laissez rien vide,
écrivez « aucun » si c'est le cas.

**Aucune valeur secrète ici.** On dit quels secrets existent, à quoi ils
servent et où les régénérer. Jamais leur contenu.
